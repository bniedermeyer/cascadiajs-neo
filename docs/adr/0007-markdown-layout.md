# Markdown Pages Use a MarkdownLayout Wrapping Layout.astro

Markdown pages (`src/pages/**/*.md`) render through a dedicated `src/layouts/MarkdownLayout.astro` rather than pointing directly at `Layout.astro`. `MarkdownLayout` is a faithful port of the legacy Enhance `simple-page.mjs` element: it wraps `Layout.astro` (the `main-layout` equivalent) and adds the page chrome that `simple-page` provided — a `#page` container, a `.page-title` bar (overcast-gray background, sound-navy heading), and a `.page-body` whose desktop width is controlled by a `width` frontmatter value (`narrow` = 50%, default; `wide` = 70%). Frontmatter flows in via Astro's `frontmatter` prop; `description` falls back to `title` when absent so authoring stays low-friction and meta tags never ship empty.

The port carries a single scoped `<style>` block. This is a deliberate, localized exception to Tailwind-first styling, and it is *permitted by* — not a violation of — ADR-0003's exception clause: markdown-generated elements (`<a>`, `<li>`, `<img>`, and a `.toc` nav) are authored as plain markdown and therefore **cannot** receive utility classes. Styling them requires CSS selectors, which is exactly the case ADR-0003 reserves for `<style>`. Because Astro's scoping does not pierce slotted markdown content, the body-element rules use `:global(...)` under `.page-body`. A comment at the top of the block records why the exception lives here and must not be copied into ordinary components.

The non-obvious parts: (1) markdown pages get their page chrome from a layout the author opts into via `layout:` frontmatter, not from `Layout.astro` directly — `Layout.astro` stays chrome-free and is shared with hand-built pages; (2) the scoped `<style>` is defensible specifically because the styled elements are unreachable by utilities, and this reasoning does not generalize to components whose markup the author controls.

Supports the fidelity policy (ADR-0001) and is verified the same way as all styling (ADR-0004, computed styles). Does not supersede ADR-0003 — it applies ADR-0003's existing exception clause.
